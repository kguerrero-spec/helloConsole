# Gestion Financiera

## Descripcion
Programa para gestionar gastos e ingresos desde consola.

## Funcionalidades
- Añadir, editar, eliminar y listar gastos
- Añadir, editar, eliminar y listar ingresos
- Resumen financiero

## Validaciones
- No se permiten importes negativos
- No se permiten posiciones invalidas
